# Responsive Image Gallery

## 📌 About
This is a Responsive Image Gallery developed using HTML, CSS, and JavaScript as part of the CodeAlpha Web Development Internship.

## ✨ Features
- Responsive layout
- Image categories (Nature, City, Animals, Flowers, Space)
- Lightbox image viewer
- Next & Previous navigation
- Hover animations
- Smooth transitions
- Mobile-friendly design

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript
